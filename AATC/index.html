Version v0.3.0 Released!

Additions:

Added Background Management!

  • Backgrounds:
    • Backgrounds preview as images, including foregrounds, so you know how they should look in-game
    • Backgrounds do not require foregrounds, but foregrounds require backgrounds
    • Characters can be used to preview backgrounds
    • There are 4 default characters
      • Defense (Phoenix Wright)
      • Prosecution (Miles Edgeworth)
      • Witness (Larry Butz)
      • Counsel (Maya Fey)
    • If those characters don’t suit your needs, you can also upload an image to be used as the preview character with the custom option!
    • Background previewing is a bit slow, but still functional.
    • You can rename backgrounds and add/remove foregrounds.
    • Coming soon, you’ll be able to change the background of CAM to match a background of your choice!
      • This is a feature that will exist just for fun.
      • An options menu will be added allowing you to restore the original background, as well as some other options.

Changes:

File Management

  • Changed how files load in CAM
    • Added an option to load from URL
    • Modified the export process so that everything is now in a “Custom Assets” folder.
      • This changed the importing process as well, so any zip files made in older versions will now warn you that they may not import properly.
    • Added example files to my website
      • These will be the default URLs when you click Load from URL, and are a great way to test the program out.
      • There exists 6 example files currently
        • An example.ogg file (The Truth Revealed 2016)
        • An example.wav file (Jingle - A Quick Breather)
        • An examplebg.png file (The Spirit of Justice Defense)
        • An examplefg.png file (The Spirit of Justice Defense Foreground)
        • An example.zip file (A zip file containing the first 4 items on this list)
        • An examplechar.png file (Phoenix Wright from Spirit of Justice)
          • This is the default for custom character previews in the background editor

Bug Fixes

General:

  • Fixed a bug where the editor would improperly load the buttons, showing the wrong names on a button
